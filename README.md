# অ্যাডভোকেট চেম্বার পোর্টফোলিও — ডেমো সাইট

ঢাকার একজন সুপ্রিম কোর্ট আইনজীবীর (ডেমো পারসোনা: **অ্যাডভোকেট মো. আবদুল লতিফ**) পোর্টফোলিও ওয়েবসাইট।
কাস্টমারকে ডেমো হিসেবে দেখানোর জন্য বানানো — বাংলা ও ইংরেজি, দুই ভাষাতেই।

ফ্রেমওয়ার্ক: **Next.js** (App Router)। ভার্সেলে সরাসরি লাইভ করা যাবে।

## সাইটে কী আছে

- **হোম** — হিরো, ট্রাস্ট-স্ট্যাটস, ৬টা প্র্যাকটিস এরিয়া, আইনজীবীর পরিচয়, ফলাফল, প্রসেস, ফি, মতামত, FAQ, চেম্বার ভিজিট ইনফো
- **প্র্যাকটিস এরিয়া বিস্তারিত** — `/services`
- **পরামর্শের অনুরোধ ফর্ম** — `/start` — ব্রিফ বানিয়ে WhatsApp / ইমেইলে পাঠায়
- **ভাষা বদল** — নেভের **EN / বাং** টগল (সব টেক্সট দুই ভাষায় লেখা)
- **মোবাইল** — নিচে ফিক্সড বার: কল / WhatsApp / পরামর্শ বাটন
- SEO: JSON-LD (Attorney/LegalService schema), sitemap, robots, OG কার্ড

## ডিজাইন

- পালেট: গাঢ় নেভি `#0E1626` + গোল্ড `#B8892F` + আইভরি `#F4EEE1`
- ফন্ট: Fraunces (ইংরেজি শিরোনাম) · Tiro Bangla (বাংলা শিরোনাম) · Outfit / Hind Siliguri (বডি)
- সব ফন্ট self-hosted (@fontsource) — Google Fonts-এ নির্ভরতা নেই

## লাইভ করার আগে — ২ মিনিট

`lib/site.js` খুলুন। ক্লায়েন্টের আসল তথ্য বসান:

- `email` — চেম্বারের ইমেইল
- `whatsapp` — দেশ কোডসহ, শুধু সংখ্যা। যেমন `"8801712345678"`
- `phone` / `phoneDisplay` — ফোন নম্বর
- `chamber`, `hours`, `availability` — ঠিকানা, সময়, অ্যাভেইলেবিলিটি
- `facebook` / `linkedin` — খালি রাখলে বাটন দেখাবে না

কনটেন্ট বদলাতে:

- প্র্যাকটিস এরিয়া, ফলাফল, মতামত, FAQ, প্রসেস → `lib/ui.js`
- পরামর্শ ফি / এনগেজমেন্ট প্যাকেজ → `lib/site.js`-এর `engagements`
- ছবি → `public/images/` (portrait, consult, chamber — আসল ছবি দিলে বদলে দিন)

শেয়ার-কার্ডের ছবি (`app/opengraph-image.png`) নতুন নামে বানাতে:

```bash
make-og.js-এ নাম-লাইনগুলো বদলান, তারপর: npm run og
```

## ভার্সেলে লাইভ

1. এই রিপো GitHub-এ পুশ করুন
2. [vercel.com/new](https://vercel.com/new) থেকে রিপো ইমপোর্ট করুন
3. Framework নিজে থেকে **Next.js** ধরবে। Build command বদলানোর দরকার নেই
4. Deploy

কাস্টম ডোমেইন বসালে Vercel-এ environment variable দিন:

```
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

এটা সাইটম্যাপ আর শেয়ার-কার্ডের লিংকের জন্য। না দিলেও সাইট চলবে।

## লোকালে চালানো

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # প্রোডাকশন বিল্ড চেক
```

## নোট

- সাইটের নাম, ছবি, নম্বর, মতামত — সবই ডেমো কনটেন্ট। ক্লায়েন্টের আসল তথ্য বসিয়ে নিতে হবে।
- পোর্ট্রেট/চেম্বারের ছবি AI-জেনারেটেড — আসল ছবি বসানোর জায়গা রাখা আছে।
