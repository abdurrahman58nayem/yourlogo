# YourLogo

ঢাকা থেকে একটা আইডেন্টিটি স্টুডিওর পোর্টফোলিও সাইট। ক্লায়েন্টকে দেখিয়ে কাজ নেওয়ার জন্য বানানো — বাংলা ও ইংরেজি, দুই ভাষাতেই।

ভার্সেলে সরাসরি লাইভ করা যাবে। ফ্রেমওয়ার্ক: Next.js।

## লাইভ করার আগে — ২ মিনিট

`lib/site.js` খুলুন। এখানে আপনার তথ্য বসান:

- `email` — ক্লায়েন্টের মেইল এখানে আসবে
- `whatsapp` — দেশ কোডসহ, শুধু সংখ্যা। যেমন `"8801712345678"`
- `phoneDisplay` — দেখানোর নম্বর, যেমন `"+880 1712-345678"`
- `instagram` / `facebook` / `behance` — খালি রাখলে বাটন দেখাবে না
- `availability` — “নতুন প্রজেক্ট নিচ্ছি” বদলাতে চাইলে

প্যাকেজের দামও এই ফাইলে: `packages`।

## ভার্সেলে লাইভ

1. এই রিপো GitHub-এ পুশ করুন
2. [vercel.com/new](https://vercel.com/new) থেকে রিপো ইমপোর্ট করুন
3. Framework নিজে থেকে **Next.js** ধরবে। Build command বদলানোর দরকার নেই
4. Deploy

কাস্টম ডোমেইন বসালে Vercel-এ environment variable দিন:

```
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

এটা সাইটম্যাপ আর শেয়ার-কার্ডের লিংকের জন্য। না দিলেও সাইট চলবে।

## সাইটে কী আছে

- হোম: কাজ, সার্ভিস, প্রসেস, স্টুডিও, প্যাকেজ, মতামত, প্রশ্ন
- ১২টা আইডেন্টিটি কেস স্টাডি — `/work/nokshi` ইত্যাদি
- প্রজেক্ট ফর্ম — `/start` — ব্রিফ বানিয়ে ইমেইল বা WhatsApp-এ পাঠায়
- ভাষা বদল: ন্যাভের **EN / বাং**
- মোবাইলে নিচে “প্রজেক্ট শুরু” বাটন

## নিজের কাজ বসানো

নতুন প্রজেক্ট `lib/projects.js`-এ যোগ করুন। লোগো মার্ক `components/Marks.js`-এ। রং `lib/brands.js`-এ।

পোর্টফোলিওর মার্কগুলো এই সাইটের জন্য আঁকা অরিজিনাল আইডেন্টিটি। বিখ্যাত ব্র্যান্ডের লোগো কপি করা হয়নি — সেটা দেখালে কপিরাইট ঝামেলা, আর ক্লায়েন্ট জিজ্ঞেস করলেও বিপদ। নিজের আসল কাজ হলে `projects.js`-এ বদলে দিন।

## লোকালে দেখা

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:3000`।
